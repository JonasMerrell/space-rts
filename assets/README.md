# KEPLER CLASH! assets (style L, cel-shaded comic)

Everything here is generated by scripts, so re-running them gives the same files:

    python3 assets/tools/gen_art.py      # sprites/, icon/, manifest.json   (pycairo, ~7 s)
    python3 assets/tools/gen_audio.py    # audio/, manifest.json "audio"    (numpy+scipy, ~10 s)
    python3 assets/tools/contact.py      # preview/*.png contact sheets (review only)

`manifest.json` is the index: every file, sizes, flipbook frame counts, anchors, engine/gun
hardpoints, team & skin palettes. Paths in it are relative to `assets/`.

## Layout
- `sprites/ships/<skin>/<class>_<team>.png`: 128 px, nose faces **+x**. Classes: interceptor,
  gunship, bomber (the rock-paper-scissors triangle: interceptor > bomber > gunship > interceptor),
  scout, tanker, freighter (cargo), tug (asteroid drive). Skins: vanguard, hive, prism, junker.
  Teams: blue, red, green, yellow, neutral (pre-baked, same colours as `crates/ui/src/theme.rs`).
- `sprites/stations/<skin>/<station>_<team>.png`: 192 px. shipyard, fuel_depot, telescope,
  scanner, defense, relay, plus `asteroid_drive_<team>.png` (64 px).
- `sprites/bodies/`: `star_<yellow|orange|red|blue|white>.png` (512, radius 140 px) and `star_glow.png`;
  `planet_<type>_{flat,lit}.png` (radius 112 px; gas_blue/gas_ringed are 384 px because of the ring);
  `moon_<type>_{flat,lit}.png` (radius 54); `asteroid_<type>.png` (pre-lit, radius 32);
  `shadow_overlay.png`: draw over a `_flat` body, scaled to its radius, rotated so +x points away from the star.
- `sprites/fx/`: flipbook strips (frame i at x = i·frame_w): explosion_small/large, asteroid_impact,
  impact_kinetic/energy, shield_hit, muzzle_flash, engine_flame, smoke_puff, scan_ping; single sprites
  kinetic_shell/tracer, energy_bolt, energy_beam_body + energy_beam_core, debris_0..3, word_* comic stickers.
- `sprites/icons/`: 96 px UI icons (matter, energy, fuel, research, upgrades, power, …) plus white
  tintable `ship_*` / `station_*` silhouettes (128/192 px).
- `sprites/ui/`: bg_tile (tileable, #1b1340), halftone_tile, select_ring, target_bracket, node_marker,
  waypoint, transfer_window. `sprites/emblems/<skin>.png`: faction badges.
- `icon/ic_launcher_<density>.png`: Android launcher icon (mdpi 48 … xxxhdpi 192, plus 512).
- `audio/music/` title, orbit, battle (seamless loops), victory, defeat; `audio/sfx/` 35 effects.
  WAV PCM 16-bit mono 22050 Hz (macroquad `load_sound`). Mood: ambient synth (Jonas's pick; `--mood chiptune` still works).
  Menu sounds: menu_open/close/select/tab, toggle_on/off, slider_tick, start_game, lobby_join, purchase (+ ui_click/tap/confirm/back/error).

## Tinting
Sprites marked `"tint": true` are white with black ink; draw with `DrawTextureParams`/`color` set to the
team colour to recolour (multiply keeps the ink black). Energy beams: tint `energy_beam_body`, then
draw `energy_beam_core` untinted on top.

`preview/` holds contact sheets and an audio reel for review; don't ship it in the APK.
